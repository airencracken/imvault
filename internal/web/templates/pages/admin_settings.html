What is this instance for?

Personal, group, and public hosts are the same program at different settings rather than three programs, so these are starting points. Each one sets who may join, whether anonymous uploads are allowed, and what a new upload is visible to. None of them changes the retention window, which reaches backwards over uploads already stored.

Changing this rewrites the deadline on anonymous uploads already stored, so shortening it takes effect immediately rather than whenever the old deadlines pass. Each deadline stays measured from when that upload arrived, so anything older than a shortened window becomes collectable at once.
