# Imvault 0.10.0

Imvault 0.10.0 improves photo location recovery, adds separate location sharing
controls, and lets you tag several photos at once.

## Changes

- Recover valid JPEG GPS even when another EXIF directory is damaged. Older
  cached details refresh from the stored original when you open a photo or
  fetch its API detail. Storage failures remain retryable and previously
  recovered fields are preserved.
- Show coordinates and an OpenStreetMap link in a visible Location section.
  Owners get an explanation when the original has no readable GPS. An optional
  static map is available through `IMVAULT_MAP_URL` and `IMVAULT_MAP_KEY`.
- Set Location independently of EXIF on uploads, individual photos, and albums.
  Both settings also work through the API. Albums can restrict either category
  without exposing anything the photo itself hides.
- Select multiple photos in Your gallery and add comma-separated tags to all
  of them. Existing tags remain. The API equivalent is
  `POST /api/v1/files/tags`; the entire selection succeeds or changes nothing.
- Add Ko-fi sponsorship links through `.github/FUNDING.yml`.

## Upgrade notes

Back up the database and stored objects before upgrading. Startup applies
migrations 025 and 026 for metadata extraction versions, location policies,
and filtered download caches. Existing photos and albums default to Location
**Follow EXIF**, preserving their GPS sharing choices. Original files remain
unchanged, and re-uploading old photos is unnecessary.

**Hidden EXIF now hides camera and date from other viewers on the photo page**,
matching downloads. Owners and administrators still see all extracted details.
Choose EXIF **Shown** with Location **Hidden** to share camera details without GPS.

JPEG, PNG, and WebP downloads support independent retention of standard EXIF
and GPS fields. Mixed settings remove opaque metadata such as XMP, maker notes,
and embedded thumbnails. Video downloads remove all container metadata when
either category is hidden. Formats that cannot be safely filtered remain
unavailable for download until both effective settings allow the original.

No location can be recovered if the uploaded original contains no readable GPS.
Some photo export and sharing options omit GPS even when the photo library shows
it. The owner-facing explanation helps distinguish that case from hidden data
or a temporary read failure.
