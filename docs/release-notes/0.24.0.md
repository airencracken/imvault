# Imvault 0.24.0

The admin dashboard now matches the other Comfyware apps and adds activity
reporting.

- It records successful local and community sign-ins and opens of content
  people are allowed to see. A view counts once per account, item and UTC day.
  Thumbnails, background assets, failed requests and signed-out visits do not
  count.
- It shows the past seven UTC days: daily totals, recent sign-ins by account,
  the most-viewed content, and when recording began.
- Only active administrators can see it. Members, moderators and guests
  cannot.
- Recording starts at the upgrade; earlier history is not reconstructed.
  No IP addresses or browser identifiers are stored.
- Activity is kept for 90 days and removed when its account is deleted.

The upgrade adds new tables and leaves existing data alone. Back up before
upgrading. Existing backup archives still restore.
