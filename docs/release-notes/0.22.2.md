# Imvault 0.22.2

A maintenance release.

- OpenID Connect sign-in now uses the shared Comfylib OIDC module. Sessions and
  permissions behave as before.
- Styles and browser controls come from Comfylib 0.3.0.
- The manual release workflow now validates the requested tag.

There is no database migration. Back up before upgrading. If you are coming
from an older version, read the earlier notes for any migrations you skipped.
