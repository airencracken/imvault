# Imvault 0.20.4

Invitation and account styles, invitation availability, and browser layout
assertions now come from the published Comfylib v0.1.7 module. Common forms and
records keep their existing layout and palette while sharing one implementation.
Application templates, permissions, and atomic invitation redemption remain local.

The release adds regression contracts for the shared CSS route, stylesheet load
order, and each application's invitation representation. Browser checks cover
four widths, both themes, keyboard access, and JavaScript enabled and disabled.

There is no new database migration. Native amd64 and arm64 packages and their
container images use the same tested release binary. See [installation](../releases.md)
and [containers](../containers.md).
