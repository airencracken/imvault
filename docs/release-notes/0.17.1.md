# Imvault 0.17.1

Member profiles support an optional name, short plain-text bio and up to five
labeled HTTP/HTTPS links under Settings → Account → Profile. Profiles require
sign-in and are linked from file and album authors. Your own export includes
your profile, including when you have no uploads.

This patch release uses the pinned Docker Official Debian image from Amazon
ECR Public for Debian package lifecycle tests. Docker Hub pull throttling
prevented the 0.17.0 release workflow from publishing its packages. Both amd64
and arm64 package gates remain required.

[Docker's official image registry documentation](https://www.docker.com/blog/news-from-aws-reinvent-docker-official-images-on-amazon-ecr-public/).

Migration 031 adds empty optional profile storage, validated through Comfylib
0.1.5. Stop the service and back up the full data directory before upgrading,
then restart the updated service.
