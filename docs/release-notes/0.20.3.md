# Imvault 0.20.3

Invitation management and account forms now share their layout, typography,
spacing, and controls with the other Comfyware apps. Invitations use a compact
create form and readable records that stack on mobile. Decorative eyebrow
labels are removed; useful context remains ordinary text.

The release includes browser checks at four widths, light and dark themes,
keyboard navigation, no-JavaScript flows, and invitation schema and mutation
regressions. The mutation gate primes its module cache before offline tests.

There is no new database migration. Native amd64 and arm64 packages and the
corresponding container images contain the same tested release binary. See
[installation](../releases.md) and [containers](../containers.md).
