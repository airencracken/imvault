# Imvault 0.27.0

- Select a larger set of files in the signed-in web uploader. Imvault sends
  them in smaller batches and reports what was saved, skipped, or failed.
- Choose **Skip files already in your library** when importing to skip exact
  duplicates among your own active files. Also available to API clients.
- Upload results show when a file was saved but its tags or album could not
  be added, with a link to organize it from your gallery.
- Search files by description, browse by month taken, and step between photos
  without leaving your filtered gallery.
- HEIC, HEIF and AVIF uploads show conversion guidance for JPEG, PNG and WebP.

No database migration is needed.
