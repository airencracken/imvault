# Imvault 0.13.1

Quieter defaults for a family library, public house rules, and backups that no
longer stop the server.

## Before you upgrade

- Back up with the old binary. Saved policies and explicit settings stay in
  effect. Unconfigured instances now require invitations and reject anonymous
  uploads, and so does Docker Compose.
- Images over 24 megapixels are refused before decoding. Uploads are processed
  one at a time by default; raise the concurrency if your host has room.
  Existing larger images stay available.
- An HTTPS base URL forces secure cookies, whatever the cookie setting says.
- Account exports build the whole ZIP on disk before sending it. Set `TMPDIR`
  if the system temporary directory is too small.
- There is no database migration.

## Changes

- **About & house rules** lists active administrators and moderators, with the
  contact details and rules saved in Admin Settings. Private labels say that
  staff can see private files and link to that page.
- When registration is closed, the home and sign-in pages offer **Have an
  invitation?**. Invitation codes still work.
- Backups run while the server keeps serving. Older running servers are
  refused.
- `backup --output-dir DIRECTORY` creates a uniquely named snapshot and keeps
  the newest seven. `--keep N` changes the count; `--keep 0` keeps all.
  Rotation happens only after a verified backup and never deletes manual or
  unrelated snapshots.
- systemd packages include an optional daily backup timer, and a cron example
  ships for OpenRC. Neither is on by default: create a private destination and
  enable one. Keep copies off the host too.
- Backups run as root read the service's storage and encryption settings
  before switching to its account, including custom disk and S3 paths.
- A failed export now returns an error instead of a broken download.
- The file view counter is gone. The API field remains for compatibility.

See [operations](../operations.md) for timer and cron setup, retention and
recovery drills.
