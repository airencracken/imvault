# Imvault 0.28.2

- Shared album cards keep the title, member name, and badges inside one border.
  The album and member profile each have their own link.
- Album pages put photos and clips up front, with two thumbnail columns on
  phones. Adding files, discussions, and settings open on demand.
- Large albums show all their files across pages. File counts reflect what each
  viewer can see, and the picker can find older uploads that can still be added.
