# Imvault 0.10.1

This patch release fixes authentication, mail delivery, and OpenRC configuration
issues found during the Comfyware audit.

## Changes

- Password reset and OpenID Connect sign-in require the account's enabled TOTP
  factor or a recovery code before granting a session. The code prompt now
  describes all sign-in methods accurately.
- Password changes revoke sessions, outstanding reset links, and pending
  second-factor attempts in one transaction. Reset redemption and the password
  update also succeed together or leave the link usable for another attempt.
- Administrator removal, demotion, and disabling preserve at least one enabled
  administrator, including when requests run concurrently.
- SMTP STARTTLS refuses plaintext fallback. Timeouts and cancellation cover the
  relay greeting, TLS handshake, and message exchange. Leading dots in email
  bodies are preserved by letting the SMTP transport escape them once.
- OpenRC configuration is installed with mode 0600, including the Gentoo and
  Alpine recipes. Source reinstallation tightens existing regular configuration
  files without replacing local settings.

## Upgrade notes

Back up your data before updating. There are no new database migrations.
Accounts with two-factor authentication now see the code prompt after password
recovery or provider sign-in. If you lost the second factor and recovery codes,
ask an administrator to clear it before signing in.

For an intentionally unencrypted local mail relay, set `IMVAULT_SMTP_TLS=none`.
The default `starttls` setting requires the relay to support TLS.

On an existing OpenRC installation, ensure `/etc/conf.d/imvault` is readable only
by root (`chmod 0600 /etc/conf.d/imvault`). If SMTP credentials were stored in a
world-readable file on a shared host, replace those credentials.

To invalidate sessions and reset links issued by an older version, change your
password after upgrading. Existing sessions are not automatically removed by
the upgrade itself.

The downloads include Linux amd64 and arm64 binaries, Debian packages, source,
and SHA-256 checksums. See [installation and upgrades](../releases.md).
