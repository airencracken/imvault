# Imvault 0.21.0

- Set up the first owner in a browser with `imvault setup`. It prints a private
  key for the setup page, asks for the password twice, and closes once an owner
  exists.
- `create-owner` and `set-password` work the same way across Comfyware apps:
  a hidden, confirmed prompt by default, plus `--password-prompt`,
  `--password-stdin`, `--password-file` and `--data-dir`.
- `set-password` ends the account's existing sessions and revokes its reset
  links.
- `create-admin` still works as an alias for `create-owner`.
