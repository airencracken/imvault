# Imvault 0.20.2

Imvault now publishes container images for Linux amd64 and arm64 at
`ghcr.io/airencracken/imvault:v0.20.2`. Each image holds the same binary as the
native release, plus CA certificates, timezone data, zstd for automatic
backups, and ffmpeg and ffprobe for clips.

The Compose example keeps data on a private volume, runs as a non-root user
with a read-only root filesystem and limited temporary space, and publishes the
port on loopback only. You can still build from a source checkout with
`docker-compose.build.yml`.

See [containers](../containers.md) for version pins, first-owner setup,
backups, upgrades and a restore drill.

There is no database migration. If you are coming from before 0.20.0, read the
[0.20.0 notes](0.20.0.md) first. Back up the stopped data volume before
upgrading. To downgrade across a schema change, restore the pre-upgrade backup
and run the matching older binary or image.

Version tags are never moved. Security updates ship as a new patch version.
