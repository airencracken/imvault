# Imvault 0.26.1

- Upload forms start with camera details and location hidden. Sharing either requires an explicit choice, including when JavaScript is disabled. Switching an upload to Public clears both choices when JavaScript is available.
- Cancelling and reopening a confirmation dialog no longer loses the action when a delayed close event arrives.
- Color palettes keep Imvault's fonts and heading weights.
- Uses Comfylib 0.7.2. No database migration is needed.
