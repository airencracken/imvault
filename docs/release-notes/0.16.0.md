# Imvault 0.16.0

Talk about an album in Witmoot. An album owner can save or remove a link to an
existing Witmoot discussion. Anyone signed in who can see the album can start a
draft for a new discussion, or a reply in an existing one. The draft carries
only the album link: no private titles, descriptions, covers, counts or
contents. You finish in Witmoot, with its own sign-in, destination choice and posting
step. Imvault never creates discussions or notifications on its own.

Set `IMVAULT_WITMOOT_URL` and `IMVAULT_BASE_URL` to turn it on. If a member
connects their Witmoot account, Witmoot can show a public album's current title
and public image count. That preview needs an API key with access to the album.
Private and members-only albums return 404, and private, members-only and
expired files and videos are left out of the count.

Albums work as before when Witmoot is down or not configured. See
[album discussions](../discussions.md) for setup and permissions.

Stop the service and back up the complete data directory before upgrading.
Startup adds a table for discussion links. To go back, restore the pre-upgrade
backup and the old binary.
