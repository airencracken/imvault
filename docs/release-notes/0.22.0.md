# Imvault 0.22.0

- An optional **Apps** menu links to your other Comfyware apps.
- Community sign-in with OpenID Connect, linked to an account only when its
  owner chooses. Imvault never creates or links accounts by matching email
  addresses. Local accounts and passwords keep working.
- Account and Library navigation is simpler. Optional upload details sit in
  collapsible sections; audience choices stay visible.
- Private albums show a neutral badge.
- After you post a Witmoot discussion about an album, Witmoot returns you to a
  confirmation page. Saving the discussion link takes a normal signed-in form.
- Imvault refuses dangling configuration symlinks and leaves their targets
  alone.
- Source builds need Go 1.26.11 or newer. golang.org/x/crypto is now v0.59.0.

Read [Comfyware connections](../suite.md) to configure the menu and shared
sign-in. Back up the stopped data directory before upgrading. Configuring
shared sign-in adds a table for linked identities. Keep the pre-upgrade backup:
to return to older binaries, restore it instead of opening the migrated
database with an older version.
