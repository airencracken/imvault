# Imvault 0.20.5

The gallery’s bulk **Add to album** picker now includes **Create a new album**,
even when you have no albums yet. Select photos, choose that option, enter a
title and click **Add to album**. The new album and all selected memberships
are saved together; a failed or unauthorized selection leaves no empty album.

New albums start private, with contributions managed by their owner. Existing
photo visibility, metadata policies and other album memberships stay unchanged.
The new album appears in the normal album picker after creation. Titles accept
up to 120 characters. Gallery search, sort, date filters and page are retained.

The flow works with JavaScript disabled and at mobile widths. With JavaScript
enabled, a missing title keeps the selected photos and focuses the title field.
The bulk album API also accepts `album: "new"` with `album_title`, retaining its
existing `{"updated": N}` response.

There is no new database migration; schema 034 and Comfylib v0.1.7 are unchanged.
Back up before upgrading, install the package or image and restart Imvault.
See [installation](../releases.md) and [containers](../containers.md).
