# Imvault 0.17.0

Add a member profile with an optional name, a plain-text bio and up to five
labeled HTTP/HTTPS links under Settings → Account → Profile. Usernames stay
unchanged; clearing the fields removes them. File and album author links open
profiles. Every profile requires sign-in, including authors of public uploads.

Profiles do not list private files, albums, account email, quotas or credentials.
Your own account export includes your profile, including when you have no files.
Disabled or deleted accounts have no readable profile. Deleting an account
removes its profile, and late writes cannot recreate it.

Migration 031 adds empty optional profile storage and uses Comfylib 0.1.5 for
shared field validation. Stop the service and back up the full data directory
before upgrading, then restart the service.
