# Imvault 0.14.0

Correct sideways photos with **Rotate left** and **Rotate right** on the photo
page. **Reset rotation** restores the uploaded orientation.

The correction appears in gallery thumbnails and previews. It belongs to your
photo, so another member's copy of the same upload stays unchanged. Original
bytes and metadata sharing settings are preserved. **Download rotated photo**
saves a full-resolution PNG without metadata; the original link still opens
the original. Videos and animations cannot be rotated.

Backups retain the correction. Account exports include the original and its
clockwise rotation in the manifest; API file responses expose `rotation` and
`preview_url`. Rotated images share the upload decode budget, enforce the
24-megapixel limit, and use validators and versioned preview URLs. Large rotated
downloads are prepared one at a time.

Back up with the old binary before upgrading. Startup applies migration
`029_photo_rotation.sql`. Restoring an older binary requires the corresponding
pre-upgrade database. Existing uploads start with no manual correction.
