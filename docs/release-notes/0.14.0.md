# Imvault 0.14.0

Fix sideways photos. On a photo's page, choose **Rotate left** or **Rotate
right**. **Reset rotation** puts it back the way it was uploaded.

Gallery thumbnails and previews show the new orientation. The rotation is
yours: another member's copy of the same upload is unaffected. The original
file and its metadata sharing settings stay as they were. **Download rotated
photo** saves a full-resolution PNG without metadata; the original link still
opens the original. Videos and animations cannot be rotated.

Backups keep rotations. Account exports include the original and its clockwise
rotation in the manifest. API file responses add `rotation` and `preview_url`.
Rotated images obey the 24-megapixel limit.

Back up with the old binary before upgrading; startup migrates the database.
To go back, restore the pre-upgrade database with the older binary. Existing
photos start unrotated.
