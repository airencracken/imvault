# Imvault 0.19.0

Imvault now backs itself up while it runs. The first backup starts a minute
after startup, then one runs every 24 hours. Backups use zstd when it is
installed and gzip otherwise.

Imvault keeps up to seven automatic backups, at most 10 GiB in total. A backup
fails if the data it copies exceeds 5 GiB before compression. Old copies are removed only
after a new one succeeds. Manual and pre-migration backups are never touched.
Owners can see the last success, any failures, the next attempt and the limits
in instance settings.

See [automatic backups](../automatic-backups.md) to change the schedule, copy
backups off the host, and recover. There is no database migration. Back up with
your current binary before upgrading: automatic backups protect the data after
startup, not before the upgrade.
