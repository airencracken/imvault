# Imvault 0.19.0

The running service now makes private verified compressed backups automatically.
The first attempt starts one minute after startup, then every 24 hours. zstd
is preferred when installed; gzip is the built-in fallback.

At most seven automatic copies are retained within a 10 GiB compressed archive
cap. Each uncompressed snapshot has a 5 GiB copy cap. Rotation runs only after
a successful snapshot and leaves manual and pre-migration backups alone.
Owners can check the last success, failures, next attempt and caps in instance
settings. All three apps use Comfylib 0.1.6 for this behavior.

See [automatic backups](../automatic-backups.md) for environment overrides,
recovery and off-host copying. No database schema migration is added. Take a
backup with the currently installed binary before upgrading; this new worker
protects the state after startup, not the state before an earlier upgrade.
