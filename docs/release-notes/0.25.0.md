# Imvault 0.25.0

Choose how times and dates appear. Open `/settings/account`, find **Times and
dates**, enter an IANA timezone such as `America/Los_Angeles`, and select
**Save timezone**. The choice follows your account to every device. UTC is the
default.

**Use this device's timezone** fills in the field when JavaScript is on. You
still save it yourself. Choosing and saving a timezone works without
JavaScript.

Sign-in and backup times on the admin dashboard follow your choice. Reporting
days stay in UTC, and so do stored timestamps and API responses. Camera dates
without a recorded offset show as captured.

The database schema and export format are unchanged. Back up the stopped data
directory before upgrading and keep that copy in case you need to downgrade.
