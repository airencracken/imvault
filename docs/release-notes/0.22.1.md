# Imvault 0.22.1

Includes everything in [0.22.0](0.22.0.md), plus:

- OpenRC and Docker Compose now pass the optional app navigation and community
  sign-in settings through to the server. The shipped templates show them
  disabled.

Read [Comfyware connections](../suite.md) to configure them. Back up the
stopped data directory before upgrading. Configuring shared sign-in adds a
table for linked identities. Keep the pre-upgrade backup: to return to older
binaries, restore it instead of opening the migrated database with an older
version.
